# 🎵 NAS Music Cleaner

> 飞牛 NAS / Linux NAS 音乐库智能清理工具

`NAS Music Cleaner` 是一个面向 NAS 音乐库的命令行清理工具，用于整理长期积累的 MP3、FLAC、APE、WAV、M4A 等音乐文件。

它采用 **“先清洗文件名 → 重新扫描 → 再智能去重”** 的两阶段处理方式，避免因为文件名中的编号、码率、下载来源标记等杂质导致重复歌曲无法识别。

---

## ✨ 功能

### 1. 🧹 自动清洗文件名

自动去除文件名前面的数字编号：

```text
01. 陈奕迅 - 愚人快乐.mp3
02- 陈奕迅 - 遥远的她.mp3
026_ 周杰伦 - 晴天.mp3
```

清洗后：

```text
陈奕迅 - 愚人快乐.mp3
陈奕迅 - 遥远的她.mp3
周杰伦 - 晴天.mp3
```

同时支持清理常见的下载来源、音质和版本标记：

```text
[320k]
[128K]
[mqms2]
[高清]
[无损]
【高清】
【无损】
(DJ版)
(Live)
(Remix)
(现场版)
```

例如：

```text
陈奕迅 - 愚人快乐 [mqms2].mp3
```

变成：

```text
陈奕迅 - 愚人快乐.mp3
```

---

## 2. 🔍 智能识别重复歌曲

工具会根据清洗后的：

```text
歌手 - 歌名
```

生成标准化 Key。

例如：

```text
陈奕迅-愚人快乐.mp3
陈奕迅 - 愚人快乐.mp3
01. 陈奕迅 - 愚人快乐 [mqms2].mp3
```

清洗后统一识别为：

```text
陈奕迅 - 愚人快乐
```

因此可以识别为同一首歌曲。

---

## 3. 💿 无损优先

重复歌曲不会简单地“随机删除一个”。

工具会按照音质进行选择。

优先级：

```text
FLAC
APE
WAV
ALAC
DSF
DFF
        ↓
MP3 / M4A / AAC / OGG / OPUS / WMA
```

也就是说：

```text
周杰伦 - 晴天.mp3
周杰伦 - 晴天.flac
```

默认：

```text
保留：FLAC
删除：MP3
```

---

## 4. 🎚️ 有损格式优先最高码率

如果重复文件都是有损格式，则优先保留码率更高的文件。

例如：

```text
陈奕迅 - 十年_128k.mp3
陈奕迅 - 十年_320k.mp3
```

优先：

```text
保留：320K
删除：128K
```

工具会优先通过 `ffprobe` 获取音频实际码率。

如果无法获取，则尝试从文件名中识别：

```text
320k
256k
192k
128k
96k
64k
```

# 🔄 工作流程

工具采用两个独立阶段。

```text
                 NAS 音乐库
                     │
                     ▼
             ┌───────────────┐
             │  第一阶段      │
             │  文件名清洗    │
             └───────┬───────┘
                     │
                     ▼
             去编号 / 去杂质
                     │
                     ▼
             统一文件名格式
                     │
                     ▼
             重新扫描音乐库
                     │
                     ▼
             ┌───────────────┐
             │  第二阶段      │
             │  智能去重      │
             └───────┬───────┘
                     │
                     ▼
             歌手 + 歌名匹配
                     │
                     ▼
              音质质量排序
                     │
                     ▼
             ┌───────────────┐
             │ 保留最佳文件   │
             │ 删除重复文件   │
             └───────────────┘
```

## ⚠️ 为什么必须先清洗再去重？

例如 NAS 中存在：

```text
陈奕迅 - 愚人快乐 [mqms2].mp3
MP3 声音文件/陈奕迅-愚人快乐.mp3
```

如果直接按照原始文件名查重：

```text
陈奕迅 - 愚人快乐 [mqms2]
陈奕迅-愚人快乐
```

很容易被认为是两个不同的歌曲。

第一阶段清洗后：

```text
陈奕迅 - 愚人快乐.mp3
陈奕迅 - 愚人快乐.mp3
```

重新扫描之后才能可靠识别为重复歌曲。

# 🖥️ 系统要求

理论上支持任何能够运行 Python 3 的 Linux NAS。

已针对以下环境设计：

* 飞牛 NAS / FNOS
* Debian
* Ubuntu
* 其他 Linux NAS

推荐：

```text
Python >= 3.9
```

如果需要准确读取有损音乐码率，建议安装：

```text
ffprobe
```

通常可以通过安装 FFmpeg 获得。

检查：

```bash
ffprobe -version
```

如果能够正常显示版本信息，则说明已经安装。

# ▶️ 使用方法

假设音乐库目录：

```text
/vol00/音乐/upan
```

## 预览

**强烈建议第一次运行使用预览模式。**

```bash
python3 nas_music_cleaner.py "/vol00/音乐/upan"
```

预览模式：

* 不修改文件
* 不删除文件
* 显示准备清洗的文件
* 显示发现的重复歌曲
* 显示预计删除数量

---

# 🧹 第一阶段：清洗文件名

确认预览结果没有问题之后：

```bash
python3 nas_music_cleaner.py \
"/vol00/音乐" --clean
```

程序会要求确认：

```text
请输入 CLEAN 确认：
```

输入：

```text
CLEAN
```

才会执行。

---

## 第一阶段不会删除文件

例如：

```text
陈奕迅 - 愚人快乐 [mqms2].mp3
```

只会修改成：

```text
陈奕迅 - 愚人快乐.mp3
```

不会删除任何音乐文件。

---

# 🔍 第二阶段：重新扫描并去重

第一阶段完成之后，重新运行：

```bash
python3 nas_music_cleaner.py \
"/vol00/音乐" --dedupe
```

程序会：

1. 重新扫描音乐库
2. 根据新的文件名生成歌曲 Key
3. 查找重复歌曲
4. 显示保留和删除结果
5. 等待确认

例如：

```text
歌曲：陈奕迅 - 愚人快乐
------------------------------------------------------------

【保留】 128K     .mp3
/vol00/.../陈奕迅 - 愚人快乐.mp3

【删除】 128K     .mp3
/vol00/.../其他目录/陈奕迅 - 愚人快乐.mp3
```

确认后输入：

```text
DELETE
```

才会真正删除。

---

# ⚡ 一次执行完整流程

如果已经充分确认工具行为，可以：

```bash
python3 nas_music_cleaner.py \
"/vol00/音乐" --execute
```

执行：

```text
第一阶段
    ↓
清洗文件名
    ↓
重新扫描
    ↓
第二阶段
    ↓
查找重复歌曲
    ↓
显示最终删除清单
    ↓
确认
    ↓
删除重复文件
```

完整流程需要两次明确确认：

```text
请输入 YES 确认执行：
```

然后：

```text
请输入 DELETE 确认删除重复文件：
```

# 🎯 重复文件保留规则


原始目录：

```text
音乐/
```


# ⚠️ 注意事项

### 1. 建议先备份

虽然程序设计了多重确认，但删除操作仍然具有风险。

重要音乐库建议先备份。

---

### 2. 不建议直接对整个 NAS 根目录执行

推荐：

```text
/vol00/.../音乐/upan
```

而不是：

```text
/vol00
```

---

### 3. 文件名识别不是音频指纹识别

当前版本主要依据：

```text
歌手 - 歌名
```

进行重复判断。

它无法可靠识别：

```text
周杰伦 - 晴天.flac
Jay Chou - Sunny Day.mp3
```

是否是同一首歌曲。

同样，如果两个不同歌曲恰好具有相同的：

```text
歌手 - 歌名
```

也可能被判断为重复。

因此建议：

> **删除前务必检查预览结果。**
